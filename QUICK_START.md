# ⚡ Démarrage rapide - RDP VM Manager\n\n## 5 minutes pour avoir l'app en local\n\n### Étape 1 : Télécharger & Extraire\n\n1. Téléchargez l'archive depuis GitHub Releases (ou clonez le repo)\n2. Décompressez le dossier\n\n### Étape 2 : Lancer l'app\n\n**Sur Windows :**\n```cmd\nDouble-cliquez sur build-app.bat\n```\n\n**Sur macOS / Linux :**\n```bash\nchmod +x build-app.sh\n./build-app.sh\n```\n\n### Étape 3 : Accéder à l'application\n\n```\nhttp://localhost:3000\n```\n\n---\n\n## Configuration (Optionnel mais recommandé)\n\n### GitHub OAuth\n\n1. Allez sur https://github.com/settings/developers\n2. \"New OAuth App\"\n3. Remplissez :\n   - **Application name** : RDP VM Manager\n   - **Homepage URL** : http://localhost:3000\n   - **Callback URL** : http://localhost:3000/auth/github/callback\n4. Copiez les valeurs dans `.env`\n\n### Tailscale\n\n1. Créez un compte : https://tailscale.com\n2. Generez une Auth Key : Settings → Auth keys\n3. Copiez dans `.env` : `TAILSCALE_AUTH_KEY=...`\n\n---\n\n## Ajouter vos VMs\n\nÉditez `config/vm-template.yml` :\n\n```yaml\nvms:\n  - name: ma-vm-rdp\n    provider: azure\n    rdp:\n      enabled: true\n      port: 3389\n    tailscale:\n      enabled: true\n      hostname: ma-vm-rdp\n```\n\nVisitez http://localhost:3000/dashboard pour voir vos VMs.\n\n---\n\n## Arrêter l'application\n\n```bash\ndocker-compose down\n```\n\n---\n\n## Besoin d'aide ?\n\nVoir `INSTALLATION.md` pour plus de détails.\n"
